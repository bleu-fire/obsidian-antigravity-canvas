# Antigravity Brand Reasoning & Generation Protocol

This skill enforces deep reasoning, strategic design planning, and prompt engineering before any node, 3D image, or wireframe is written to Obsidian Canvas.

```
┌────────────────────────┐      ┌────────────────────────┐      ┌────────────────────────┐
│  1. DESIGN REASONING   │      │ 2. PROMPT ARCHITECTURE │      │ 3. CANVAS INTEGRATION  │
│ • Semiotic analysis    │ ───► │ • Lighting & optics    │ ───► │ • 16:9 layout math     │
│ • Industry benchmarks  │      │ • Material physics     │      │ • Negative space ratio │
│ • Competitive posture  │      │ • Anti-generic guard   │      │ • Non-colliding coords │
└────────────────────────┘      └────────────────────────┘      └────────────────────────┘
```

## 1. Deep Strategic Reasoning (Phase 1)

Never jump directly to an image or card. First perform an architectural brand breakdown:

1. **Brand Identity & Semiotics**:
   - What core values must the mark communicate (e.g., cryptographic certainty, organic fluidity, architectural mass)?
   - Which geometric forms naturally express this without decorative cliché?
2. **Materiality & Light Physics**:
   - Is the object brushed titanium, matte basalt, anodized cobalt, or cast frosted glass?
   - Define exact primary and rim light angles (e.g., 45° key light, subtle cyan counter-fill).
3. **Typography & Spatial Hierarchy**:
   - High-contrast editorial titles (Grotesque or geometric sans).
   - Strict 60/40 rule: 60% negative space & optical visual weight, 40% crisp typographic block.

---

## 2. Engineered Prompt Generation (Phase 2)

### A. The 3D Brand Mark Image Formula
Convert the strategic direction into an ultra-high-fidelity generation prompt.

**Prompt Template:**
```text
Photorealistic luxury 3D brand identity mark representing [CONCEPT].
Form: [EXACT GEOMETRIC CONSTRUCTION - e.g. Monolithic beveled hexagon with precision-carved keyhole void].
Materiality: [Brushed dark gunmetal steel with micro-machined facets and warm gold interior reflection].
Lighting: [Single directional studio key light, high-contrast chiaroscuro, subtle specular edge highlight].
Environment: [Clean dark neutral studio backdrop #0A0F1D, soft subtle depth falloff, zero clutter].
Style: [Award-winning corporate identity, Pentagram / Chermayeff & Geismar level of restraint, 8k render, no cartoon, no glowing rainbow or neon AI tropes].
```

### B. Editorial Thumbnail Wireframe Formula
Structure clean, mature layouts without clickbait language.

- **Headline**: Authoritative 2–4 word title (e.g., `STRUCTURAL CERTAINTY`, `MODULAR GEOMETRY`).
- **Sub-label**: Functional specification (e.g., `System Architecture Review`, `Brand Direction 01`).
- **Composition Box**: 16:9 ratio container (`width: 620, height: 320`).

---

## 3. Execution & Canvas Layout Rules (Phase 3)

1. **Asset Generation**:
   - Generate raster art via Antigravity image models.
   - Save directly to `assets/logos/<concept-slug>.jpg`.
2. **Spatial Coordinate Math**:
   - `Origin Concept Node`: $(x_0, y_0, w_0, h_0)$
   - `Strategic Rationale Card`: $(x_0, y_0 + h_0 + 100, 320, 200)$
   - `Generated 3D Image Node`: $(x_0 + 360, y_0 + h_0 + 100, 320, 320)$
   - `Editorial Wireframe Frame`: $(x_0 + 720, y_0 + h_0 + 100, 560, 320)$
3. **Visual Cleanliness**:
   - Zero emojis in text nodes, labels, or edge markers.
   - Elegant directional arrows (`arrow` end, subtle connectors).
